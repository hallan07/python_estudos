Esse foi o curso básico no qual saí do zero para aprender Python.

A instituição Curso em Vídeo foi excelente como ponto de partida para entender sobre programação orientada a objeto
e sobre todas as funcionalidades básicas nativas do Python. Os conceitos foram apresentados de forma gradual,
sempre com exemplos práticos que simulam desafios reais, como validação de dados, contagens automáticas, cálculos, jogos e simulações.

Aprendi conceitos como estruturas de dados, repetições controladas, como evitar erros comuns em loops, usar condições compostas,
estruturas condicionais, controlar o fluxo de execução do código com if, else, elif, for e while, listas, tuplas, dicionários,
modularizar o código, funções, trabalhar com módulos e pacotes, tratamento de erros, exceções entre outros.
